- Problem: Perishable goods cannot be routed like ordinary freight; delays, traffic incidents and weather can affect a delivery.
- How it works: It requests real routes from a routing service, brings in live traffic, incident and weather data from external providers, and lets users compare the alternatives the routing service actually returns. Python Code Complexity Lab
- Problem: Estimating the complexity of code by eye is hard and error-prone, especially for beginners.
- How it works: It parses submitted Python into an Abstract Syntax Tree and applies hand-written rules to recognise structures such as loops, nested loops and recursion, then shows a complexity estimate. Code is analysed statically and never executed. The rules were tested against a dataset.
- Status: Deployed; main features tested. Results are estimates from the implemented rules and can be wrong, so continued validation is needed.
